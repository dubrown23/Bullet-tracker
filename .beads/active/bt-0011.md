# Widget — mirror the week-grid row, adopt the win rule

## Why

Last wave of the Duo / iOS 26-27 modernization. The widget is still the pre-bt-0013 design (filled circles per habit, progress ring, fixed font sizes, opaque background) and it scores with "entry exists", so an avoidance slip counts as a completion and the ring goes up when you drink.

## Plan

1. Share logic + components with the widget target: `HabitWinRule` moves from `HabitCalculations.swift` into `Data/Models.swift` (already in both targets — it is a rule about `CompletionStyle`/`CompletionState`, so it belongs with them). `AppTheme.swift`, `Color+Hex.swift`, `DesignSystem.swift` need **target membership** added for `BulletTrackerWidgetsExtension` — Xcode File Inspector action for Dustin (project file edits are blocked while Xcode is open). Widget's local failable `Color(hex:)` duplicate deleted.
2. Provider: per habit, last-7-day states (one indexed fetch over the window, grouped by habit) + today's win via `HabitWinRule`; `DaySummary`-style counts (positive done/total, clean/slips).
3. Views, all text styles / `@ScaledMetric`, palette from `AppTheme`, `.widgetAccentable()` on the coloured parts so tinted / clear Home Screen modes work:
   - Small: count ring (positive habits) + "3 clean" / "1 slip" line.
   - Medium: weekday letters + up to 3 rows of `[tile] name  ▪▪▫▪▪▫◻`; today's square is `Button(intent:)`.
   - Large: same with up to 8 rows + summary footer.
4. `CompleteHabitIntent` keeps toggling today with the app's rules (avoidance → `.failure`).
5. Build (needs step 1 membership), verify on Duo sim (widget gallery / home screen), install, ship.
