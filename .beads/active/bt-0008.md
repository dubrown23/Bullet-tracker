# iPhone Duo + iOS 26/27 modernization — Wave 1: Foundation

## Why

Dustin got an iPhone Duo (foldable) 2026-10-24. The app's window now changes size while it runs (fold / unfold). Code audit (Explore agents, 2026-10-24) found the app is structurally modern (NavigationStack, List/Form, `@Observable`, two-arg `onChange`) but has a handful of things that break or look wrong when the window isn't the whole screen, plus a design-language gap vs. iOS 26/27 (Liquid Glass). This is Wave 1 of 4 — the small set of changes that every later wave depends on.

Later waves (separate beads): `bt-0009` Duo layout (size classes, adaptive grids, Journal strip), `bt-0010` design language (toolbars, glass, Dynamic Type, accessibility labels, deprecated-API sweep), `bt-0011` widget (accentable, scaled sizes).

## Out of scope

- Any size-class or layout work (bt-0009).
- Typography, accessibility labels, toolbar restructuring, glass effects (bt-0010).
- Widget changes (bt-0011).
- Data model / SwiftData / CloudKit — untouched.

## Plan

1. Raise app target `IPHONEOS_DEPLOYMENT_TARGET` 18.4 → 26.0 (widget already 26.0; Dustin's devices are on 27.1). Unlocks the `Tab` API, `ShareLink` presentation behaviour, Liquid Glass APIs without `#available`.
2. `DashboardComponents.swift:23` — drop `UIScreen.main.bounds.width - 40` seed; start `containerWidth` at 0 and treat "not yet measured" as "don't scroll, use a sane cell size". GeometryReader already updates it.
3. Share sheets → `ShareLink` (SwiftUI, anchors itself, works in any window):
   - `DayJournalView.swift:857-869` `shareText` presents `UIActivityViewController` on `UIApplication.shared.connectedScenes.first`. Replace the menu Button with a `ShareLink(item:)`.
   - `BackupRestoreViewModel.swift` — `captureSourceView` GeometryReader + detached `UIView` anchor + `connectedScenes.first` + `createBackup(from:sourceView:)`. Replace with: create backup → store URL → `ShareLink` / `.sheet` with `ShareLink` button, no UIKit presentation.
   - `JournalExportView.swift:206-221` `ShareSheet: UIViewControllerRepresentable` → `ShareLink`.
4. `ContentView.swift` — `TabView` with `.tabItem` → `Tab(_:systemImage:value:)` API + `.tabViewStyle(.sidebarAdaptable)`. Outline icons only (system picks filled variant). Rename private `enum Tab` → `AppTab` to avoid clash with SwiftUI's `Tab`.
5. Delete `Notes/NotesView.swift` — only referenced by its own `#Preview`; the live Journal tab is `DayJournalView`.
6. Trim `AppTheme.swift` to what's used (`accent` only) — or keep the semantic colours if bt-0010 will want them. Decision: keep `accent`, `success`, `partial`, `failed` (bt-0010 will route hex literals through these); delete `Spacing`, `Radius`, `Shadow`, `Font`, `ShadowStyle`, and the three unused `appCard*` modifiers.
7. Build. Run on iPhone Duo simulator folded + unfolded and on Dustin's device. Before screenshots taken first for comparison.
8. STATUS.md update; ship.
