# One "win" rule + honest Today header + pinned grid header

## Why

Dustin (2026-10-25): "1 of 11 complete — some of the habits are negative, so 11/11 is actually negative." Root cause: every calculation in the app (Today count, current/best/overall streaks, Dashboard completion rates, heatmap, PDF summary, Journal "Completed") treats *an entry exists with state ≠ notDone* as "completed", regardless of `Habit.completionStyle`. For an **avoidance** habit the entry means you slipped, so the count goes up when you slip, the streak counts drinking days, and a perfect clean month is a row of empty squares. For **multi-state**, "Tried" (`.failure`) counts the same as "Success".

Also from Dustin: the Today header + letters + habits scroll as one block; the table header should stay fixed and only the habit rows scroll.

Decisions (Dustin, 2026-10-25, after examples):
1. **Win rule** — simple: checked; multi-state: success or partial ("Tried" is an honest miss, not a win); avoidance: the day passed with no slip, today counts as clean so far.
2. **Log Details → Done only saves the details**; it never changes the day's state. The square is the only thing that changes your numbers. (When the sheet auto-opens after a check, the check already happened.)
3. Header fixed, habits scroll.

## Out of scope

- Widget (`bt-0011`) — it still shows raw "entry exists" circles; will adopt the rule when it mirrors the grid row.
- JSON export's per-entry `completed` flag (raw data export, not a score).

## Plan

1. `HabitCalculations.swift`: pure `HabitWinRule.isWin(style:state:isFuture:)` + `HabitCalculationService.isWin(for:in:on:)`; replace every `isCompleted(in:on:)` / `!= .notDone` check in streaks, completion rate, batch stats, heatmap.
2. `HabitDataRepository.swift`: `HabitStore.isWin(for:entry:on:)` convenience; `HabitCompletionState.isCompleted` keeps meaning "marked/logged" (row visuals).
3. `TodayViewModel.swift`: `DaySummary` (positive done/total, avoidance clean/slips) + `summaryText` — "5 of 8 done · 3 clean" / "· 1 slip" / "All 8 done".
4. `TodayView.swift`: summary card → `navigationSubtitle`; weekday letters → `safeAreaBar(edge: .top)` (pinned, like the Journal strip); the List holds only habits.
5. `TodayHabitCardView.swift`: avoidance squares — clean past tracked day = filled habit colour (a win), slip = failed red (✕ when selected), today clean = outline; slips written as `.failure` (model's documented shape) instead of `.success`.
6. `HabitCompletionDetailView.swift`: Done saves details with the day's *existing* state (or `.notDone` if none); hide the "How'd it go?" picker when there's no entry yet.
7. `DayJournalView.swift`: include note-only (`.notDone` + details) entries under Activity Details; split "Completed" into Completed / Slipped.
8. `JournalPDFGenerator.swift`: per-habit + overall completion via `calculateCompletionRate` (win rule).
9. Tests for the win rule. Build; verify Duo + iPad sims; install; ship.
