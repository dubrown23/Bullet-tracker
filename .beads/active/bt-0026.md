# Today row — one round control on the left, six quiet dots on the right

Design pass 2026-10-29. Dustin looked at the Today screen cold ("the idea
is good but something is still off, I want it to feel native"), saw four
layouts side by side on the Duo simulator (`Habits/TodayRowMockView.swift`,
a throwaway debug screen under Settings → Developer) and picked **option 2**.

## Why

The row's job and its layout disagree. Dustin logs mostly by voice, so the
Today screen is for a glance and the occasional correction. The thing he
does on it is mark today, and today is the smallest, rightmost of seven
identical squares (`bt-0013`'s week grid). Six squares of history carry the
same weight as the one control; the row reads as a tiny chart with a name
attached, not a checklist. Apple's checklists put one big round control on
the left and nothing competing beside the name (Reminders).

Seen on the simulator the same morning, all consequences of the grid:

- Names truncate ("Wor…", "Medi…") on the folded Duo: the grid plus the
  flame badge leave ~46 pt for the name.
- A done day fills in the **habit's** colour, so a red habit's done days
  look like slips and an avoidance habit's clean today is a red outline.
- The weekday letters float above the card and read as part of the title.
- Rows change height when stepping days: the Auto caption exists on today only.
- "All 3 done" over four rows reads as a bug (the avoidance row is excluded).
- An avoidance habit's empty square invites the tap that means "I slipped".
- Log Details is reachable only by long-press, which Dustin never finds.
- The title says "Yesterday" while VoiceOver still says "Today".

## Plan

Option 2 as mocked, plus the polish Dustin agreed to fold in (2026-10-29).
Activated the same day with three changes from Dustin: the row opens Log
Details (item 8 = yes), the dots are display-only, and the Avoiding
trailer counts slips only.

**The row**

```
 ◯  🍴 Diet                          ● ● ○ ● ● ●   🔥4
        Auto · 118 / 180 g · 2,106 cal        [Back to Auto]
 ◯  🏃 Workout                       ● ◐ ● ○ ● ●   🔥3
 ◯  📖 Reading                       ● ● ● ○ ● ●
 AVOIDING                                          1 slipped
 ⊘  🍃 Weed                          ○ ○ ○ ○ ○ ○
```

The round control and the dots are the **shared style** the Journal and
Dashboard turns adopt later (`DayControl` / `DayDot` beside `DaySquare`).

1. **Round control on the left**, the selected day's state, state colours
   only (`AppTheme.success` / `partial` / `failed` / `rest`), 44 pt hit
   area, symbol-replace bounce on change. Simple: `circle` ↔
   `checkmark.circle.fill`. Multi-state cycles done → partial → tried →
   clear on the one control (Reading is the only such habit; leave it).
   Avoidance: `circle` ↔ `xmark.circle.fill`; the empty state uses a
   slashed-circle glyph so the opposite meaning is visible.
2. **Glyph + name** at full width, the habit's colour on the glyph only.
3. **Six dots** for the six days before the selected day, oldest first,
   state-coloured, grey when empty, in straight columns (fixed trailing
   slot for the flame whether or not a row has a streak). **Display only,
   not buttons** (Dustin, 2026-10-29: below the 44 pt tap size and easy to
   hit by mistake). A past day is edited through Log Details, now one tap
   away, or by stepping the day arrows. VoiceOver gets the six days as one
   summary value on the row.
4. **Flame + count** in the fixed trailing slot. Streak counted with
   `allowingOpenToday: true` like the Dashboard, so the two agree at breakfast.
5. **Caption on its own full-width line** under the row, for **any** day
   the graded habit has numbers for (not today only), so rows keep their
   height when stepping days. Back to Auto stays on that line.
6. **Avoidance habits in their own section** headed "Avoiding"; its
   trailer counts **slips only** ("1 slipped", nothing when there are
   none — never "clean", the `bt-0024` rule the Dashboard uses). The main
   subtitle then counts positive habits only ("3 of 3 done"); `DaySummary`
   wording in `Data/Models.swift` is shared with the widget, so change it there.
7. **The weekday-letter header goes** (`safeAreaBar` + `WeekdayLetterStrip`
   in `TodayView`). The day arrows and the "Today" button stay as they are.
8. **Tap the row → Log Details; the round control is the only way to
   mark.** (Dustin, 2026-10-29: yes.) The long-press menu keeps Log
   Details, Rest, Back to Automatic, Edit, Delete as the backup.
9. Fix the title's accessibility label ("Yesterday" must read as such).
10. `DaySquare` stays for the Journal / Dashboard strips; the new pieces
    (`DayControl`, `DayDot`) live beside it in `Utilities/DesignSystem.swift`.
11. Delete `Habits/TodayRowMockView.swift` and its Settings → Developer row
    at the end of the build.

**Tests** (Swift Testing, in `Bullet_TrackerTests.swift`): section split
(avoidance vs positive, order kept); subtitle wording counts positive
habits only; Avoiding trailer says "1 slipped" / nothing, never "clean";
dot window = the six days before the selected day; control symbol + colour
per state and style; streak on the row uses the open-today rule.

**Pass test** (Duo simulator first, then DBd, one action at a time): tap
Diet's circle → green check with a bounce, subtitle +1; tap it again →
clears; tap Weed's control → red X, "1 slipped" in the Avoiding trailer,
tap again → the trailer is empty; tap a dot → nothing flips (the dots sit
inside the row's button, so Log Details opens, which is the row's tap); tap
the Reading row → Log Details opens; Previous day → rows keep their height,
the control shows yesterday's state, the dots shift by one; VoiceOver
reads "Yesterday"; a long name ("Meditation") shows in full.

## Result (2026-10-29, shipped)

Built in plan order in one sitting. `DayMark` / `DayControl` / `DayDot` /
`DayDotStrip` beside `DaySquare`; `DaySummary.positiveText` + `slipsText`
(the widget keeps the one-line wording); `TodayViewModel.positiveHabits` /
`avoidanceHabits` / `avoidingTrailerText`, streak with `allowingOpenToday`
and the clean-start floor; the row rewritten; `TodayView` in two sections
with the letter strip, its geometry reading and `contentMargins` gone;
`WeekGridMetrics` shrunk to `windowDays` (the date strips still use it) +
`previousDays`. 109 tests (5 new in `TodayRowTests`).

Simulator pass found three things, all fixed before the phone: the
large-title accessibility label stayed "Today" on Yesterday (re-identifying
the List didn't help; `.id(dateDisplayString)` on the `NavigationStack`
did), "Test Workout" truncated on the folded Duo (names now wrap to two
lines, like a Reminders title), and a dot tap opens Log Details because the
dots sit inside the row's button — kept, since nothing flips. The fake dh
re-ticks Test Sauna within seconds of an uncheck on the simulator; that is
`FakeHealthFacts`' permanent inbox tick, not the row. iPad Air sim: two
columns, nothing truncated, both orientations; a captioned row's partner
sits 8 pt lower (PairedRows centres the pair), pre-existing.

**Dustin's phone pass: 9 of 9**, one action at a time — mark Poison
(green check, bounce, flame 2 → 3), clear it, Weed slip ("1 slipped" in
red on the Avoiding header), clear it, Workout row → Log Details, dot tap →
Log Details with nothing flipped, Previous day (Yesterday, rows keep their
height), Today. Mock screen deleted.
