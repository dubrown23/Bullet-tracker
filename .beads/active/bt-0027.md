# Bullet copies Apple Health workouts + their heart rate to dh

Plan agreed with Dustin 2026-11-09 (step 2 of dustin-system in_flight
`dh-bullet-health-pipe-2026-11-09.md`). dh's receiving side is live
(`dh-0030`, `op=health`).

## Why

Since ~Nov 4 the Claude iPhone app turns off connector tools for the rest of
a chat once Claude has read Apple Health. Voice reading Health breaks voice
logging. Bullet is an app and may read Health, so Bullet becomes the only
reader and copies what dh needs; voice then reads dh only. Step 0 (2026-11-09)
proved Bullet can read every field dh takes (718 HR readings in one workout,
all fields matched Fitness).

## Plan

- `POST ?op=health`, same base URL + Bearer key as `op=sync`. Body
  `{ workouts, samples }`, ≤ 50 workouts and ≤ 5,000 samples per send.
- Workouts: apple_uuid, activity_type (dh's own name table, copied — dh
  refuses a name/code disagreement), activity_code, start/end (ISO with
  zone), duration_seconds (**Apple's duration, pauses excluded** — Dustin
  chose A; dh loosens its 5 s check), active_energy_kcal, distance_m, HR
  avg/min/max, source_device, source_bundle_identifier. Unreadable → omitted.
- Samples: every heart-rate reading inside each workout's start/end.
- New since last send = an anchored query on workouts from 2026-10-28; the
  anchor is saved only after dh replies to every chunk.
- On open (beside the habit sync, separate from it) + HealthKit background
  delivery for workouts (observer query registered at launch). iPhone with
  the key only; the iPad never calls dh.
- Settings → Dustin's Health: last send, why, counts, refused reasons, and
  "Send all again from Oct 28".
- Step 0 test screen removed after the proof passes.

## Out of scope

- All-day heart rate, sleep, steps to dh (later lines on the list).
- Deleted workouts (dh has no delete op for Bullet).
- The Health permission wording (lives in the project file).

## Outcome (shipped 2026-11-10)

- Backlog: the first open sent all 19 workouts since Oct 28 with 10,232
  heart-rate readings; "Send all again" then got 0 new / 19 already had,
  0 refused — dh never doubled.
- Background proof (2026-11-09): a 20-minute test workout with Bullet closed
  and Xcode stopped → "Apple Health sent 3:58 PM · background wake-up",
  1 workout, 277 readings. Hockey practice reached dh by itself at 8:35 PM.
- Step 0 test screen (`HealthWorkoutProofView`) and its Settings link
  removed; "Last checked" now shows only when a later check found nothing.
- 117 unit tests pass on the Duo simulator (7 new in `HealthCopyTests`).
