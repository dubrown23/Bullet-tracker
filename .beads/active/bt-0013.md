# Prototype: week-grid Today row

## Why

Dustin played with the bt-0012 row (icon tile as the checkbox) and said it feels dated and not intuitive. Survey of current habit apps: Reminders/Things = circle checklist (reads as a to-do list); Streaks = big press-and-hold tiles (hides the pattern); Everyday / Loop / HabitNow = **week grid** — habit left, last 7 days as real cells right, tap today's cell to complete. The week grid makes "log fast" and "glance at the pattern" the same gesture on the same pixels, which is the app's stated purpose. Dustin asked to judge it by feel → throwaway branch `proto-week-grid`, installed on the Duo. Keep or discard after his reaction.

## Out of scope

Everything except the Today row. No data changes.

## Plan

1. `TodayHabitCardView`: row = [coloured icon glyph, no background] [name] [🔥n] … [7 day cells]. Cells ~24pt (`@ScaledMetric`), today's cell outlined in the habit colour until done, then filled; past cells filled by that day's state (simple: habit colour; multi-state: green/orange/red; avoidance: red when slipped) or systemGray5. **Whole row is the button** (44pt+ target per HIG) — tap completes/cycles today; long-press menu = Edit / Delete / Log Details; swipe = Edit / Delete. ⓘ leaves the row (details sheet still auto-opens on completion; "Log Details" in the menu re-opens it). `ViewThatFits`: one line when it fits, otherwise name above the grid.
2. Build, sanity-check on Duo sim, install on Dustin's Duo.
