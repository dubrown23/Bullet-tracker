# iPhone Duo + iOS 26/27 modernization — Wave 3: Design language

## Why

The audit (2026-10-24) found the app structurally modern but visually behind iOS 26/27: hand-built toolbar stacks (Today's "+" jumps between the Duo's side rail and a bottom capsule; New Habit sheet loses Cancel/Save when scrolled), a fake material bar for the Journal date strip, 25 hard-coded font sizes (8–28pt) that ignore Dynamic Type, **zero** accessibility labels in the whole app, the main habit checkbox as a tap gesture rather than a button, UIKit haptics, the legacy `Alert` API, `.cornerRadius` / `foregroundColor`, and blue buttons on the Backup screen against an orange accent. Dustin's rule: Apple's guidelines whenever possible. Approved 2026-10-24.

## Out of scope

- Layout / size-class work (done in `bt-0009`).
- Widget (`bt-0011`).
- Behaviour changes. One open product question (Done in Log Details saves a record without completing the habit) is parked until Dustin answers.

## Plan (grouped; build after each group)

A. **Toolbars** — HIG Toolbars + SwiftUI 27 toolbar reference. Today: date arrows as a `ToolbarItemGroup` of `Label` buttons (icon-only), "Today" + "+" as trailing items, `ToolbarSpacer` between groups; drop manual 44pt frames and manual `.opacity` for disabled. `.navigationBarLeading/Trailing` → `.topBarLeading/Trailing` or semantic placements everywhere. Investigate the New Habit sheet's vanishing Cancel/Save.
B. **Journal date strip** — becomes a `safeAreaBar(edge: .top)` on the List (iOS 26 API: custom bar that gets the system scroll-edge treatment) instead of a VStack with `.ultraThinMaterial`. Day cells stay flat content (HIG: don't over-glass; glass is for the floating control layer).
C. **Typography** — every `.font(.system(size:))` → a text style (keeping `design: .rounded` / weight where used). Fixed frames that would clip larger text get `minWidth/minHeight`.
D. **Accessibility** — Apple VoiceOver nutrition label: every icon-only control is a `Label` (`.labelStyle(.iconOnly)`) or gets `.accessibilityLabel`; checkbox → `Button` with `.accessibilityLabel` + `.accessibilityValue` + `.accessibilityAddTraits(.isToggle)`-style value; colour swatches and icon grid get names; hand-built radio list in Export → `Picker(.inline)`.
E. **Deprecated / off-system** — `UIImpactFeedbackGenerator` → `.sensoryFeedback`; Settings legacy `Alert` → `alert(_:isPresented:presenting:actions:message:)`; `.cornerRadius` → `.clipShape`; `foregroundColor` → `foregroundStyle`; Backup/Restore filled-blue buttons → `.borderedProminent` / `.bordered` (`.controlSize(.large)`), tinted by the app accent.
F. Build, verify on Duo sim (folded) + iPad sim (regular), one session at a time; install on Dustin's Duo; ship.
