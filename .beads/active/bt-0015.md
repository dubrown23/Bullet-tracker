# Consistency pass — five rules, applied app-wide

## Why

Dustin (2026-10-25): "what else needs a polish for Apple style… I don't want to do one-offs." Grep of the app after bt-0008–0014: 21 literal colours (`.green/.orange/.red/.yellow`) across 6 files beside a one-place palette; two visual languages for "seven days" (Journal 44×56 tiles r10 vs Today squares); corner radii 2/6/8/10 and icon tiles 28/36/44 hand-set; hand-drawn capsule chips where iOS has toggle buttons; 6 custom `listRowInsets`; Journal title inline while the other tabs are large.

## Rules (the deliverable)

1. **One palette.** `AppTheme.accent / success / partial / failed` only. No literal colours in app code. Exception: `.red` as the destructive tint on swipe Delete (system semantic).
2. **One shape rule.** Continuous corners at 22% of the element's size (`AppShape`), one `HabitIconTile` used everywhere an icon sits on a tint.
3. **One "seven days" family.** `WeekdayLetterStrip` + `DaySquare` shared by Today's grid and the Journal's date strip (day number inside the square; selected = accent fill, today = outline).
4. **System chips.** Workout type / duration = `Toggle … .toggleStyle(.button).buttonBorderShape(.capsule)`.
5. **Standard chrome.** Large titles on tab roots (Journal joins), inline on sheets; default row insets except where a grid needs edge-to-edge; day/column labels in the grouped-header style (`.sectionLabel()` = caption, uppercase, secondary); heatmap keeps caption2 (cells can be 7pt).

## Plan

1. `Utilities/DesignSystem.swift`: `AppShape`, `HabitIconTile`, `DaySquare`, `WeekdayLetterStrip`, `sectionLabel()`.
2. Apply rule 1 (palette) across SettingsView, BackupRestoreView, HabitFormView, HabitDetailDashboardView, HabitDashboardView, HabitCompletionDetailView, TodayHabitCardView, DayJournalView.
3. Apply rule 2: tiles in Dashboard row, habit detail header, habit form, Journal data row; `IconSelectorView` cell shape.
4. Apply rule 3: Today uses the shared strip/square; Journal strip rewritten on the same components (7-day window via `WeekGridMetrics.windowDays`, arrows move by a week, tap a square to select).
5. Apply rule 4 in Log Details.
6. Apply rule 5: Journal large title; drop custom insets (Today header padding follows); labels.
7. Build; verify Duo + iPad (one at a time); install; ship.
